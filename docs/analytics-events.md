# 花鳥風月、そして魚と虫。のイベント

2026年11月23日確認。送信先は `G-K6SPCN20DE`。主要行動は既に実装済みのため、今回は実行コードを増やしません。

| 既存イベント | 発火条件 | 内容 |
|---|---|---|
| quiz_start | デッキを開始、間違いの復習を開始 | quiz_mode=deck/retry |
| quiz_answer | 問いへの回答が受理されたとき | 回答本文は送らない |
| quiz_timeout | 回答時間が切れたとき | 回答本文は送らない |
| quiz_complete | その回を終えたとき | analyticsPassCompleteで重複を防止 |

実装は `index.html` 内の `startDeck`、`answer`、`timeoutAnswer`、`finishPass` です。`NaoyamanAnalytics` はイベント名・パラメータを限定し、send_toを指定しています。新たな同義イベントは不要です。

## 送信範囲

計測先はこのサイトの既存GA4ストリームに限定します。新しいGoogleタグやconfigは追加していません。自由入力、検索語、回答本文、氏名、URLのクエリやハッシュを追加イベントのパラメータに含めません。自動page_view・scroll・外部リンク計測と同義のイベントも追加しません。

## 確認方法

Googleへの実送信を伴わない局所検証と、既存CIを使います。公開後の確認は変更した資産と代表ページに限定します。送信コードの確認と、GA4管理画面での受信確認は区別します。
